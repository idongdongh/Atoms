# 项目文档

本目录保存 Atoms 的长期有效文档，包括开发计划、架构决策、接口约定、安全模型和运维说明。

## 当前文档

- `phase-1-development-plan.md`：第一阶段 Builder 内核的范围、架构、里程碑与验收标准。
- `phase-2-development-plan.md`：第二阶段全栈交付、GitHub 同步与生产发布的范围、里程碑与 Beta 门禁。
- `adr/`：已经接受的系统级架构决策。

## 维护约定

- 文件名使用小写英文和连字符。
- 影响系统边界的决定应在实现前写入文档。
- 开发计划发生变化时，先更新对应文档，再修改代码和任务拆分。
- 临时草稿使用明确的 `draft-` 前缀；结论合并到正式文档后删除草稿。
- 过期文档不得静默保留，应更新、归档或删除，并修复所有引用。
- 新增子目录前先创建该目录自己的 `README.md`，说明职责、内容和清理规则。
