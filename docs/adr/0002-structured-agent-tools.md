# ADR 0002：Agent 只使用结构化工具协议

- 状态：accepted
- 日期：2026-08-25

## 决策

Agent 的读写、搜索、验证和运行操作通过带运行时 Schema 的 Tool Calling 完成。自由文本只能作为用户可见说明，不能触发系统副作用。

## 原因

- 输入可以在执行前验证。
- 每个工具调用可以独立审计、重试和恢复。
- 权限与审批可以绑定到工具而不是解析模型文本。
- 避免残缺 XML、Markdown Code Fence 或自然语言歧义导致错误写入。

## 用户影响

执行进度来自真实工具事件，页面刷新后仍能还原，而不是展示模拟进度。
