# Product

## What it is

A web-based AI app builder: describe an idea in natural language, and an
agent turns it into a running, publishable application — with real-time
preview, versioned edits, an optional database, and one-click publishing.

## Users

People who want small web apps built quickly without setting up toolchains,
and reviewers evaluating AI-native full-stack engineering.

## Core loops

1. Describe an idea → the agent plans, edits files, and commits versions.
2. Watch the live preview update as the code changes.
3. Keep chatting to iterate; roll back to any earlier version safely.
4. Publish to a public URL in one click; share it with a QR code.

## Principles

- The agent only works through validated, structured tools — never raw shells.
- Git is the source of truth for generated code; the database stores metadata.
- What you see in the preview is what gets published.
